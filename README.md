### ⚡ Event-Driven Trading Engine

An event-driven trading architecture designed around separated market-data, strategy, execution, and portfolio components.

```text
Market Data
    ↓
Fetcher
    ↓
Normalizer
    ↓
Event Loop
    ↓
Strategy
    ↓
Execution
    ↓
Portfolio / Risk
```

**Stack:** Rust
